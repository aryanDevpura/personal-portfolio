# Aryan Devpura - Personal Portfolio

A personal profile webpage built as a single-page website to showcase my education, technical skills, projects, and contact details.

## About the Project

This project was created as part of the coursework for the Web Technology course. The goal was to build a clean, functional, and responsive personal portfolio using fundamental web technologies without relying on frontend frameworks or external UI libraries.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Sections

The webpage is structured as a single-page layout with smooth navigation across the following sections:

- About: A brief personal overview and background in programming.
- Education: Academic history at Manipal Institute of Technology and prior schooling, including relevant coursework.
- Skills: Technical skills grouped into Languages, Frontend, Backend, AI/Agent Systems, Databases, and Tools.
- Projects: Overview of software projects with descriptions, tech stacks, and source links.
- Interests: Personal hobbies outside of academics and coding.
- Contact: Direct email and profile links to GitHub, LinkedIn, and LeetCode.

## Deployment

The website is configured to be hosted on GitHub Pages:

- Live Website: https://<username>.github.io/<repository-name>/

## Local Setup

To view the project locally:

1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser.
