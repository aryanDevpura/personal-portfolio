Projects

Poseidon

Persistent-Memory AI Agent Harness

Poseidon is an AI agent system that keeps its memory across sessions instead of starting fresh every time. The backend runs on FastAPI and uses LangGraph to manage cyclic agent states, so the agent can plan, act, and reflect in a loop. For retrieval, it uses a hybrid approach: sqlite-vec handles vector similarity search over stored embeddings, while FTS5 does full-text keyword ranking. Both results get combined so the agent can pull up relevant past context when responding. The frontend is built with React.

CodeInsight AI

AI-Powered Code Review Tool

A web app where you can write or paste code into a Monaco Editor in the browser, and get it reviewed by the Google Gemini API. The backend is a Node.js/Express server that sends the code to Gemini and parses the structured response back. It flags things like syntax issues, code smell, and possible performance problems. The frontend uses React and Tailwind CSS. Deployed on Vercel (frontend) and Render (backend).

Personal Finance Tracker

Full-Stack Web Application

A budgeting and expense tracking app with user authentication built using JWT and bcrypt. The backend is a Node.js/Express REST API connected to a PostgreSQL database through Prisma ORM. Users can log expenses, view spending breakdowns, and manage their budget. The frontend is React with Tailwind CSS. The database is hosted on Neon, frontend on Vercel, and backend on Render.
